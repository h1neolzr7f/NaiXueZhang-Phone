这是装在手机上的独立软件。不需要先开电脑工作室，也不遥控电脑。

小白三步
  1. 设置里填 NovelAI Token 和 DeepSeek Key。
  2. 发现里搜图，点☆收藏入本地库。
  3. 本地库选人、看画风，点「整系列换角并入队」。

下载安装
  1. 用手机浏览器打开：
     https://github.com/h1neolzr7f/NaiXueZhang-Studio-Upgrade/raw/cursor/android-phone-standalone-9162/android/download/NaiXueZhang-Phone-1.5.2.apk
  2. 等 APK 下完后打开。若系统拦截，到设置里允许「安装未知应用」。
  3. 先卸载旧的「Nai学长工作室」再装，避免签名冲突。
  4. 核验 SHA256：
     2a8c1adbe6b4b8c60bf711c6344779f68c76e33c638cd877c8bb6a3cbdcdc8ca

当前版本：1.5.2-phone.16（versionCode 167）
只要 64 位 Android。这是 debug 签名包。
公开源码：https://github.com/h1neolzr7f/NaiXueZhang-Phone

钥匙
  · NovelAI Token：出图。每行一个，几个就能并发几路。
  · DeepSeek Key：用中文写角色槽、把整段 OC 拆栏。
  Token 只写进应用私有存储，日志里不会打印。

网络
  · 搜图 / 写角色可以走代理。
  · 出图默认直连，避免开了代理反而生成不了。
  · Clash 填 HTTP，例如 http://127.0.0.1:7890，不要只开全局 VPN / TUN。
  · 还被网站拦：设置里点「测试在线库」或「打开在线库过验证」，或先打开「内置样例」。

日常用法
  · 在线库只负责搜图收藏。必须先入库才能换角色和生成。
  · 点☆会立刻收屏幕上的图和咒语，不用等原图。
  · 收藏后走本机：本地库、图库、排队、换角断网也能看。
  · 作品页能看原图咒语、识别到的画风词和换角后的草稿预览。
  · 换角请点开搜索，输入即搜；中文会自动对英文 tag。
  · 本机打进电脑同款全量 D 站角色包（约 35 万），也有明日方舟库、OC（整段咒语，支持 {{权重}} ）和画风。
  · 多女角按槽位各选人。自定义就是写 OC。
  · 整段 OC 可贴给 DeepSeek 拆栏，已是标签就立刻填好。
  · 换角方式都摊开：本页换角 / 按槽位 / 全部页 / 整系列入队。也可写服饰替换、额外添加、移除标签。
  · 只换画风用「整系列换画风」。
  · 队列有进度条、当前阶段和预计还要多久。顺序是出图 → 入库 → 超分 → 打码。
  · 失败可手动重试或删除，不会自动重试。
  · 图库按任务分组。打码默认关，可选不打码，或像素 / 模糊 / 线条 / 纯色 / 黑条 / 表情。
  · 也可进某一组再点「对这组打码」。部位：欧金金 / 欧芒果 / 欧派派 / 欧西利。
  · 打码模型是理塘同款 censor.onnx，已打进安装包。

不做
  · 不遥控 Windows 工作室，不配对电脑，不填 6 位配对码。
  · 不移植 Pixiv 发布、Live2D、管家 / 导演台。

从源码构建
  见 README.md。在 android/ 目录用 JDK 17 执行 ./gradlew assembleDebug。
  不要提交 android/local.properties、真实 Token、用户图库。

电脑预览（开发用）
  python3 scripts/phone_preview_server.py
  浏览器打开 http://127.0.0.1:18797/m?standalone=1
